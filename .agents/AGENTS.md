# Currie Chieftains Rugby Hub - Project Rules

1. **Strict Terminology & UI Labels**:
   - Never rename, alter, or embellish existing UI labels, filter option names, titles, or Scottish rugby age group labels (P1–P7, U13–U18, 1st XV, 2nd XV, Women's, Vets) unless explicitly instructed by the user.
   - Always keep requested edits strictly scoped to the exact feature requested.

2. **No Unrequested Redesigns**:
   - Do not make unprompted changes to filter options, navigation links, or data schemas outside the requested scope.
